OmniResolve, in pictures

A customer-support AI that issues refunds, replacements and return labels, built so that it can't be tricked into doing the wrong thing. The AI only suggests; plain code decides; a human approves anything big.

1. The real-world problem, and how it's solved

Companies want AI to resolve tickets end to end, not just answer FAQs. But letting an AI touch money fails in five concrete ways.

2. What happens to one customer message

Purple steps are the AI, teal steps are plain code, coral is the human. The AI never makes the final call.

3. The saga: changes across many systems, safely

A refund can't really be undone, so it runs last among the main steps, as the "point of no return". Anything before it can be undone; anything after it is retried, never undone.

4. RAG: finding the right rule for the right date

Policies change from year to year. The search drops rules that weren't in effect on the order date before ranking, so the AI can't cite an expired rule.

5. Demo mode vs live mode

Visitors can try everything without API keys. Only the AI's answers differ between modes; the safety machinery always runs for real.
